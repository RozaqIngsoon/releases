# 🌙 Kalkulator Awal Hijriah (Windows Desktop)

Aplikasi desktop hisab astronomis & pemetaan visibilitas hilal penentuan awal bulan Hijriah berbasis Ephemeris NASA JPL DE440s (1849–2150 M / 1266–1572 H).

## 📥 Unduh Aplikasi (Siap Pakai tanpa Instalasi Python)
- **[Klik di sini untuk Mengunduh Kalkulator_Awal_Hijriah.exe](https://github.com/RozaqIngsoon/releases/raw/main/Kalkulator_Awal_Hijriah.exe)**

### Fitur Utama:
- **Dashboard & Analisis Lokasi**: Perhitungan posisi Matahari & Hilal saat Sunset (H+0 & H+1 Ijtima') serta evaluasi 6 kriteria visibilitas (MABIMS, Wujudul Hilal, Odeh, Turki, Danjon, IQG).
- **Generator Peta Visibilitas Dunia**: Pemetaan visibilitas hilal global interaktif (H+0 & H+1).
- **Galeri Peta Tersimpan**: Kelola dan pratinjau peta .PNG yang telah disimpan.
